# TrailLog

一个简单的徒步轨迹记录 App：开始 / 暂停 / 继续 / 停止保存，边走边在地图上画轨迹，
看时间、距离、爬升和速度，轨迹存在手机本地，可以导出、导入 GPX 文件。
没有账号，没有服务器，没有广告。

## 怎么拿到安装包

1. 在 GitHub 上新建一个空仓库（名字随便，比如 `traillog`），把这个项目里的
   所有文件传上去（直接在网页上点 Add file → Upload files，或者用 git push）。
2. 等 GitHub Actions 跑完：仓库顶部的 Actions 标签页里会出现一次
   “Build TrailLog IPA”的运行，几分钟后变绿就是编好了。
3. 点进那次运行，最下面 Artifacts 里下载 `TrailLog-ipa`，解压得到 `TrailLog.ipa`。

## 怎么装到手机上（侧载）

1. 在手机上装 AltStore（官网 altstore.io，按它的指引装，需要一台电脑配合一次）。
2. 把 `TrailLog.ipa` 发到手机上（隔空投送、微信文件传输助手都行），
   用 AltStore 打开安装。签名用你自己的 Apple ID 就可以，不用交 99 美元的开发者会员。
3. 免费证书 7 天过期一次，到期前在 AltStore 里点一下 Refresh 重新签名就行，
   App 和里面的轨迹都不会丢。
4. 第一次打开时，定位权限请选择“始终允许”，这样锁屏后记录也不会中断。
   如果只选“使用期间”，锁屏一会儿轨迹就断了。

## 注意

- 这个项目是在没有 Xcode 的环境下写的，第一次 GitHub Actions 编译就是真正的
  编译测试。如果 Actions 报红，点进去看是哪一步出错，把报错贴回来就能修。
- 地图用的是系统自带的 Apple 地图，需要联网加载地图瓦片；轨迹记录本身只用 GPS，
  没信号的地方也能记，只是地图底图可能显示不出来。
- 轨迹只存在手机本地的 `tracks.json` 里，删 App 就没了，记得定期把 GPX 导出来备份。
